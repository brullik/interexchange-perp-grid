# Короткий runbook владельца

## Сейчас

1. Сделать репозиторий private.
2. Загрузить fast-track архив в корень.
3. Убедиться, что CI зелёный.
4. Запустить единую цель из `CODEX_START_PROMPT_RU.md`.

## После Product Ready

Codex должен предоставить одну команду Docker Compose для shadow на VPS. Для shadow биржевые торговые ключи не нужны. Telegram можно подключить через локальный `.env`, который не попадает в Git.

## После Live Canary Ready

Создать отдельные API credentials только для выделенного аккаунта/субаккаунта бота:

- futures trading: разрешено;
- read account/positions/orders: разрешено;
- withdrawal/transfer: запрещено;
- IP allowlist: включить, если поддерживается;
- ключи хранить только на VPS вне Git.

Canary должен начинаться ровно с одного base asset, одного route, одного tranche и минимального допустимого notional. Live включается только короткоживущим Telegram challenge после успешной квалификации текущих code/config hashes.

## Аварийные действия

При любой неоднозначности:

1. `/pause` — запретить новые входы;
2. проверить позиции на всех биржах;
3. `/kill` — включить аварийный режим;
4. использовать подготовленную команду reconciliation;
5. не перезапускать live до отчёта об отсутствии остаточной дельты.
