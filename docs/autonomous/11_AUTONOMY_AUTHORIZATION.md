# Полномочия Codex

Владелец проекта разрешает Codex автономно выполнять все обратимые действия в
репозитории, необходимые для достижения master goal:

- создавать и менять branches, issues, labels, PR;
- запускать/перезапускать CI;
- исправлять code/tests/docs/workflows;
- проводить отдельный adversarial review;
- переводить собственные PR в Ready;
- squash-merge после locked gates;
- создавать tags/releases/GHCR images;
- продолжать следующей веткой и PR без отдельного подтверждения;
- создавать deployment scripts и выполнять deployment при наличии уже
  предоставленного VPS access.

Это разрешение не является согласием:

- на реальные ордера;
- на повышение risk profile;
- на withdrawals/transfers;
- на изменение exchange accounts;
- на создание или получение секретов из GitHub/чата;
- на отключение fail-closed gates.

Первый real-money canary требует отдельный `LIVE_CANARY_CONSENT`.
